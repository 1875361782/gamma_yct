档案与设置

企业档案只存在本机的扩展存储里，不会被上传。不要把密码、短信验证码、 一次性口令或人脸凭证写进档案——插件识别到这类字段会直接跳过，写进来只是徒增泄露面。

企业档案（JSON）

键名用 enterprise_registration.v1 的路径写法，例如 enterprise.name.trade_name、investors[0].name。 点「载入示例」看完整结构。

可信输入（默认开启）

点击类操作（展开下拉、点选项、勾选、下一步）走 Chrome 的调试通道 （chrome.debugger）派发真实输入事件——和你亲手点击在页面眼里 没有区别，专治政务站自绘下拉「点了没反应」。边界与代价：

  • 运行时页面顶部会出现「"一窗通填报助手"正在调试此浏览器」提示条。这是 Chrome 对该通道的固定标识，也是它保持透明的方式；点掉提示条即当场收回， 在你点面板的「重置本次运行」之前，插件不会再自动连回来。
  • 扩展只用这个通道发送鼠标/键盘输入，不读取页面内容、不执行任何脚本 （后台只放行 CDP 的 Input 域）。
  • 停用后一切照常工作：所有点击自动回退到普通合成事件，只是自绘组件的成功率会低一些。
  • 为什么这个权限在安装时就要给：Chrome 不允许把 debugger 做成「用时再申请」的可选权限，它只能随扩展一次性授予。 所以下面这个开关是软开关——停用会立刻松开所有调试附着并拒绝后续派发， 但不会（也无法）从扩展上摘掉这项权限。真要彻底收回，请在 chrome://extensions 里停用或删除本扩展。

知情提示的处理方式

政务站点在推进过程中会弹出「告知后果」类的提示，例如 一经申报无法修改企业类型、请仔细核对投资人信息。 它们要的是你点头知悉，不点就走不下去。

  • 开启后：这类提示由插件代你点「确定」，连续填报不再被打断。 每一次代点都会记进留痕，并把站点原话一并记下，事后能查清确认过什么。
  • 不开启：每次遇到都停下来，把原话摆给你看，你可以自己点， 也可以当场授权（只在本次运行内有效）。
  • 这个开关管不到的事：承诺书、声明、电子签名、实名/人脸、 支付缴费、放弃/注销，以及最终提交。那些是你本人做出承诺、 表明身份或处置财产，插件永远不代劳——它不是默认关闭的功能，是边界。

平台接入（可选）

不配也能用。配上之后，字段别名会以平台的表单结构（form_schemas）为准覆盖本地那份， 运行事件也会回写审计。当前后端下发的是录制步骤而非企业档案，所以档案仍然来自上面这个输入框。

自检

装好之后先跑一次自检：它按 manifest 的顺序加载引擎的每个模块，对合成的 Element Plus 结构跑断言，并逐个解析扩展的其余脚本。全绿说明「装上能不能跑」这一层没问题。

这个插件不做的事

  • 不读、不写、不记录密码、验证码、短信码、一次性口令。
  • 不代做实名认证、人脸识别、扫码授权、银行卡核验、电子签名。
  • 不勾选承诺书、声明、告知书一类的法律意思表示。
  • 不在业务域白名单之外的任何页面上动作。
  • 最终提交需要在面板上连点两次显式授权，且一次运行只点一次，结果不明确时不重试。
