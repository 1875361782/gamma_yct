日常用这两条就够：

### 1. 启动后端（必开）

```bat
cd /d d:\工作\伽马账\伽马注册_RPA演示包
.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8766 --log-level info
```

或一键脚本：

```bat
cd /d d:\工作\伽马账\伽马注册_RPA演示包
run.bat
```

### 2. 外网隧道（可选，另开一个终端）

```bat
cloudflared tunnel --url http://127.0.0.1:8766
```

---

**常用地址**
- 产品页：http://127.0.0.1:8766/
- 管理页：http://127.0.0.1:8766/admin
- 健康检查：http://127.0.0.1:8766/health

**说明**
- 后端窗口不要关；隧道要外网访问时再开。
- 无头由环境变量控制：生产 `GAMMA_HEADLESS=1`（默认）；本机看窗在 `backend\.env` 设 `GAMMA_HEADLESS=0` 后重启。
- 阿里云 Windows 部署：见 `伽马注册_RPA演示包\docs\ALIYUN_WINDOWS_DEPLOY.md` 与 `deploy\`。
